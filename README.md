# Mapping, Localization, and Path Planning

This project implements core navigation algorithms for a mobile robot in ROS 2.

## Included algorithms

- Particle-filter global localization
- Grid-based A* path planning
- Custom 2D occupancy-grid SLAM
- Collision checking and map-frame path generation
- TF management and RViz visualization
- Rosbag-based evaluation
